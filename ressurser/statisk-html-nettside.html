Teknologi · statisk HTML

Hva betyr en statisk HTML-nettside?

Statisk betyr først og fremst at siden leveres med ferdig innhold som normalt er likt for alle besøkende. Det sier ikke at siden må være gammeldags, uten mobiltilpasning eller uten funksjoner.

Publisert av webproduksjon.no. Dette er en praktisk veiledning om å planlegge en liten bedrifts nettside.

Hva betyr «statisk»?

En statisk nettside består normalt av ferdige filer som sendes til nettleseren. NDLA beskriver statiske nettsider som sider med samme innhold og utseende uavhengig av bruker og enhet [1]. Det passer godt når alle besøkende skal se den samme informasjonen om tjenester, åpningstider og kontakt.

Statisk betyr ikke «uten design». CSS kan styre layout og uttrykk, og siden kan være responsiv på mobil.

Hva gjør HTML, CSS og JavaScript?

HTML

Strukturerer innholdet, som overskrifter, avsnitt, lenker og bilder.

CSS

Styrer presentasjon, farger, mellomrom og responsiv layout.

JavaScript

Kan tilføre interaksjon og funksjoner når det faktisk er nødvendig.

Digdir og MDN beskriver HTML som struktur for webinnhold, mens CSS og JavaScript typisk brukes til presentasjon og funksjonalitet [2] [3].

Når passer statisk?

En håndverksbedrift, konsulent eller liten lokal tjenestebedrift kan ofte bruke statiske sider når hovedbehovet er å presentere felles informasjon og ta imot en forespørsel.

En kundeportal med innlogging, personlige bestillinger, handlekurv eller innhold som varierer mellom brukere trenger derimot dynamisk funksjonalitet eller eksterne tjenester. Det må vurderes konkret.

Hva må avklares før levering?

Avklar hvordan siden oppdateres, hvem som eier filene, hvordan den publiseres, og hvem som vedlikeholder kontaktinformasjon og bilder. En statisk løsning kan være enkel å flytte, men den redigerer seg ikke selv.

Neste steg: Beskriv hvor ofte innholdet endres og hvilke funksjoner du faktisk trenger. Det avgjør om enkel statisk HTML er en god grunnmur.

Kilder og videre lesing
